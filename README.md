# StructViz 2.0 – Static Edition

> Pure static HTML/CSS/JS build — no server required.

## Deploy (GitHub Pages)

1. Push this folder to a GitHub repo
2. Go to **Settings → Pages → Source → Deploy from branch → main / (root)**
3. Your site will be live at `https://<username>.github.io/<repo>/`

## Deploy (Netlify / Vercel)

Just drag-and-drop this folder on [netlify.com/drop](https://app.netlify.com/drop) — live in seconds.

## Local Preview

Open `index.html` directly in a browser, or run a quick server:

```bash
python3 -m http.server 5000
```
Then visit `http://localhost:5000`
