    Understanding Binary Search Tree (BST)

    Imagine a smart decision tree 🌳 where every choice depends on comparison. Smaller values go to the left, and larger values go to the right. This is how a Binary Search Tree (BST) organizes data efficiently.

    What is a Binary Search Tree?

    A Binary Search Tree is a special type of binary tree where:

    • Left child contains values smaller than the parent
    • Right child contains values greater than the parent
    • This rule applies recursively to every node

    Basic Structure

    Example BST:

    20
    /    \
    10    30
    / \
    5 15

    Here, every node follows the BST rule: left values are smaller, right values are larger.

    How Insertion Works

    Let’s insert values: 20, 10, 30, 5, 15

    1. First element becomes the root 2. Compare new value with root 3. Move left if smaller, right if larger 4. Repeat until the correct position is found

    Step-by-Step Growth

    20 → (root)

    10 goes left → 20 ← 10

    30 goes right → 20 → 30

    5 goes left of 10

    15 goes right of 10

    Traversal Methods

    • Inorder (Left → Root → Right): Gives sorted output
    • Preorder (Root → Left → Right)
    • Postorder (Left → Right → Root)

    Example Traversal

    For the above tree:

    • Inorder → 5, 10, 15, 20, 30
    • Preorder → 20, 10, 5, 15, 30
    • Postorder → 5, 15, 10, 30, 20

    Why Use BST?

    • Fast searching (O(log n) in balanced case)
    • Maintains sorted order automatically
    • Efficient insertion and deletion

    Real-Life Applications

    • Database indexing
    • Search systems
    • Auto-suggestion features

    👉 A BST is like an intelligent sorting system that organizes data as you insert it.
