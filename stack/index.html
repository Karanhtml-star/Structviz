    Understanding Stack (Data Structure)

    Imagine you are stacking books on a table 📚. You always place a new book on top, and when you need one, you remove the topmost book first. This is exactly how a Stack works in computer science.

    What is a Stack?

    A Stack is a linear data structure that follows the LIFO (Last In First Out) principle. This means the element added last is the first one to be removed.

    Basic Operations

    There are five main operations performed on a stack:

    • Push: Adds an element to the top of the stack
    • Pop: Removes the top element from the stack
    • Peek: Displays the top element without removing it
    • Overflow: Happens when we try to push into a full stack
    • Underflow: Happens when we try to pop from an empty stack

    Step-by-Step Example

    Let’s understand with a simple example. Suppose we push three elements: 10, 20, 30.

    Stack after pushing:

    Top
    30
    20
    10

    Notice how 30 is at the top because it was inserted last.

    Now, if we perform a Pop operation:

    Stack after popping:

    Top
    20
    10

    The element 30 is removed first, proving the LIFO concept.

    Real-Life Applications

    • Undo/Redo operations in editors
    • Browser history navigation
    • Function calls (Call Stack)
    • Expression evaluation (like postfix/prefix)

    👉 In short, a stack is simple but extremely powerful and widely used in programming.
