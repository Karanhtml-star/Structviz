    Understanding Heap Sort

    Imagine a tree where the largest element is always at the top 🌳. This structure is called a Heap, and Heap Sort uses this property to sort elements efficiently.

    What is a Heap?

    A Heap is a complete binary tree that follows a specific property:
    • Max Heap: Parent is greater than children
    • Min Heap: Parent is smaller than children

    How Heap Sort Works

    1. Build a Max Heap from the input array
    2. Swap root (largest) with last element
    3. Reduce heap size
    4. Heapify again
    5. Repeat until sorted

    Example

    Input:

    10 → 5 → 20 → 6

    Heap Form:

    20 at root

    Sorted Output:

    5 → 6 → 10 → 20

    Time Complexity

    • Best: O(n log n)
    • Average: O(n log n)
    • Worst: O(n log n)

    Advantages

    • Efficient for large datasets
    • In-place sorting

    Limitations

    • Not stable
    • More complex than Bubble Sort

    👉 Heap Sort is powerful and efficient, making it ideal for performance-critical applications.
