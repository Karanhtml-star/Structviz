    Understanding Queue (Data Structure)

    Imagine standing in a line at a ticket counter 🎟️. The person who comes first gets served first, and new people join at the end. This is exactly how a Queue works.

    What is a Queue?

    A Queue is a linear data structure that follows the FIFO (First In First Out) principle. This means the element inserted first is the first one to be removed.

    Basic Operations

    There are five main operations performed on a queue:

    • Enqueue: Add an element at the rear (end)
    • Dequeue: Remove an element from the front
    • Front (Peek): View the first element
    • Overflow: Occurs when the queue is full
    • Underflow: Occurs when the queue is empty

    Step-by-Step Example

    Let’s say we add three elements: 10, 20, 30 into the queue.

    Queue after Enqueue:

    Front Rear
    10 20 30

    Here, 10 is at the front because it was inserted first.

    Now, if we perform a Dequeue operation:

    Queue after Dequeue:

    Front Rear
    20 30

    The element 10 is removed first, proving the FIFO concept.

    Real-Life Applications

    • Ticket booking systems
    • CPU scheduling
    • Printer queue
    • Handling requests in servers

    👉 In short, a queue ensures fair processing by following the order of arrival.
