Bubble Sort

Simple comparison-based sorting algorithm

Controls

History

    Understanding Bubble Sort

    Imagine bubbles rising in water 🫧. The smaller bubbles stay below while the larger ones rise to the top. This is exactly how Bubble Sort works — the largest elements “bubble up” to their correct position.

    What is Bubble Sort?

    Bubble Sort is a simple sorting algorithm that repeatedly compares adjacent elements and swaps them if they are in the wrong order.

    How It Works

    1. Compare the first two elements 2. Swap them if needed 3. Move to the next pair 4. Repeat until the largest element reaches the end 5. Continue for remaining elements

    Step-by-Step Example

    Let’s sort the array: 5, 3, 8, 2

    Initial:

    5 → 3 → 8 → 2

    Pass 1:

    3 → 5 → 2 → 8

    Pass 2:

    3 → 2 → 5 → 8

    Pass 3:

    2 → 3 → 5 → 8

    Now the array is sorted.

    Key Concept

    After each pass, the largest unsorted element moves to its correct position.

    Time Complexity

    • Best Case: O(n) (already sorted)
    • Average Case: O(n²)
    • Worst Case: O(n²)

    Why Use Bubble Sort?

    • Easy to understand and implement
    • Good for learning sorting basics
    • Works well for very small datasets

    Limitations

    • Slow for large datasets
    • Too many comparisons and swaps

    Real-Life Analogy

    Think of students lining up by height 👦👧. They compare with the person next to them and swap places until everyone is in order.

    👉 Bubble Sort is simple and intuitive, making it perfect for beginners to understand sorting concepts.
